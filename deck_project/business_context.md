# Business Context

## 문서 목적

이 문서는 **AI 자동화 컨설팅 제안서**의 비즈니스 배경을 정리하는 문서입니다.  
왜 이 제안이 필요한지, 누구에게 제안하는지, 어떤 문제를 해결하는지 쉽게 설명합니다.

## 업무 목적

- 제안서의 방향을 분명하게 정합니다.
- 대상 고객이 바로 이해할 수 있는 문제와 해결책을 정리합니다.
- 슬라이드에 들어갈 핵심 메시지와 근거를 미리 준비합니다.
- 나중에 PPT를 만들 때 내용이 흔들리지 않게 합니다.

## 발표 주제

현재 주제:

- 내부 개발팀이 없는 SMB를 위한 **4주 AI 자동화 진단 및 업무 시스템 구축 컨설팅 제안**

쉽게 말하면:

- AI 도구를 소개하는 제안서가 아닙니다.
- 대표가 반복해서 처리하던 업무를 줄이는 제안서입니다.
- 회사 안에서 반복 업무가 자동으로 굴러가는 구조를 만드는 제안서입니다.

## 대상 고객

듣는 사람:

- 내부 개발팀이 없는 10~50명 규모의 SMB 대표

SMB 뜻:

- 중소규모 사업체를 뜻합니다.
- 여기서는 직원 수가 많지 않고, 별도 개발팀이 없는 회사를 말합니다.

대상 고객의 특징:

- 대표가 영업, 운영, 보고, 고객 응대까지 직접 챙기는 경우가 많습니다.
- 좋은 도구가 있어도 누가 세팅하고 운영할지 막막합니다.
- AI를 써보고 싶지만 어디부터 시작해야 할지 잘 모릅니다.
- 개발자를 채용하기에는 비용과 시간이 부담됩니다.

듣는 사람이 알고 싶은 것:

- 우리 회사에 AI 자동화가 정말 필요한가?
- 어떤 반복 업무부터 줄일 수 있는가?
- 4주 동안 무엇을 해주는가?
- 개발팀이 없어도 운영할 수 있는가?
- 비용 대비 효과가 있는가?
- 컨설팅이 끝난 뒤에도 계속 사용할 수 있는가?

## 현재 상황

고객 환경:

- 직원 수는 10~50명 정도입니다.
- 내부 개발팀이 없거나, 기술 담당자가 매우 적습니다.
- 업무가 사람의 기억, 엑셀, 메신저, 이메일에 흩어져 있습니다.
- 대표나 핵심 직원에게 일이 몰리는 구조입니다.

현재 겪는 문제:

- 반복 보고서 작성에 시간이 많이 듭니다.
- 고객 문의 응대가 늦어집니다.
- 자료 정리와 제안서 작성이 대표에게 몰립니다.
- 직원마다 업무 방식이 달라서 결과물 품질이 일정하지 않습니다.
- 바쁜 시기에는 중요한 고객 대응이나 영업 기회를 놓칠 수 있습니다.

쉬운 설명:

- 일이 어려운 것보다, 같은 일을 계속 반복하는 것이 문제입니다.
- AI 도구를 하나 더 사도 업무 흐름이 정리되지 않으면 효과가 작습니다.
- 먼저 반복 업무가 어디서 생기는지 찾고, 그 업무가 자동으로 돌아가게 만들어야 합니다.

## 핵심 문제

문제 문장 초안:

> 현재 내부 개발팀이 없는 SMB 대표는 반복 보고서, 고객 문의, 자료 정리, 제안서 작성이 한 사람에게 몰리면서 중요한 의사결정과 영업에 쓸 시간이 줄어들고 있습니다.

문제를 더 쉽게 나누면:

- **시간 문제**: 반복 보고서와 자료 정리에 시간이 많이 듭니다.
- **응대 문제**: 고객 문의에 빠르게 답하기 어렵습니다.
- **집중 문제**: 대표가 중요한 결정 대신 반복 작업에 묶입니다.
- **운영 문제**: 업무 방식이 정리되어 있지 않아 사람이 바뀌면 품질도 흔들립니다.

## 제안 서비스

서비스명:

- 4주 AI 자동화 진단 및 업무 시스템 구축 컨설팅

제안 방향:

> AI 도구 하나를 더 사는 게 아니라, 반복 업무가 굴러가는 구조를 만듭니다.

제공 내용:

- 1주차: 반복 업무 진단
- 2주차: 자동화 흐름 설계
- 3주차: AI 도구와 자동화 연결
- 4주차: 실제 업무 적용 및 운영 가이드 전달

컨설팅 결과물:

- 자동화 대상 업무 목록
- 업무 흐름도
- 보고서, 문의 응대, 자료 정리 자동화 초안
- 대표와 직원이 따라 할 수 있는 운영 가이드
- 이후 개선할 자동화 후보 목록

## 제공 솔루션 툴

이 제안서는 아래 도구를 활용합니다.  
단, 제안서에서는 도구 이름보다 **무엇을 해결하는지**를 먼저 설명합니다.

### Codex

쉽게 말하면:

- 업무 문서, 코드, 자동화 작업을 함께 정리하고 만들 수 있는 AI 작업 도구입니다.

활용 예:

- 반복 문서 구조 만들기
- 제안서 초안 정리
- 업무 자동화 스크립트 작성 보조
- 기존 파일과 폴더 구조 정리

### Claude Code

쉽게 말하면:

- 긴 문서와 복잡한 작업 흐름을 이해하고 정리하는 데 강한 AI 작업 도구입니다.

활용 예:

- 긴 회의록 요약
- 고객 문의 내용 분류
- 업무 절차 문서화
- 보고서 초안 작성 보조

### n8n

쉽게 말하면:

- 여러 업무 도구를 서로 연결해서 반복 작업을 자동으로 실행하게 하는 자동화 도구입니다.

활용 예:

- 문의가 들어오면 담당자에게 자동 알림
- 설문 응답을 표로 정리
- 매주 보고서 초안 자동 생성
- 메일, 문서, 스프레드시트, 메신저를 연결

## 핵심 메시지

가장 중요한 한 문장:

> AI 도구 하나를 더 사는 게 아니라, 반복 업무가 굴러가는 구조를 만듭니다.

보조 메시지:

- 대표가 직접 붙잡고 있던 반복 업무를 줄입니다.
- 개발팀이 없어도 시작할 수 있는 방식으로 설계합니다.
- 도구 도입보다 업무 흐름 정리가 먼저입니다.
- 4주 안에 작은 자동화부터 실제로 써볼 수 있게 만듭니다.
- 직원이 따라 할 수 있는 운영 가이드까지 남깁니다.

## 기대 효과

정성 효과:

- 대표가 반복 작업에서 벗어나 중요한 결정에 더 집중할 수 있습니다.
- 고객 문의 응대 속도가 빨라집니다.
- 보고서와 제안서 품질이 더 일정해집니다.
- 직원들이 같은 방식으로 업무를 처리할 수 있습니다.
- AI를 막연한 유행이 아니라 실제 업무 도구로 이해하게 됩니다.

정량 효과 예시:

- 보고서 작성 시간 절감: `[예: 주당 3~5시간]`
- 고객 문의 1차 응대 시간 단축: `[예: 평균 1일 → 2시간 이내]`
- 제안서 초안 작성 시간 절감: `[예: 3시간 → 40분]`
- 반복 자료 정리 시간 절감: `[예: 월 10시간 이상]`

주의:

- 실제 수치는 고객사의 현재 업무량을 진단한 뒤 확정합니다.
- 제안서에서는 검증되지 않은 숫자를 단정하지 않습니다.

## 제안서 말투

기본 말투:

- 대표가 바로 이해할 수 있게 씁니다.
- 어려운 기술 용어는 짧게 풀어서 설명합니다.
- “AI가 다 해줍니다”처럼 과장하지 않습니다.
- “어떤 업무가 얼마나 줄어드는지”를 중심으로 말합니다.

좋은 표현 예시:

- `AI 자동화` → `반복 업무를 자동으로 처리하게 만드는 방식`
- `워크플로우` → `업무가 흘러가는 순서`
- `시스템 구축` → `누가 해도 같은 방식으로 처리되는 구조 만들기`
- `AI 에이전트` → `정해진 일을 대신 처리하도록 설정한 AI 도우미`

피해야 할 표현:

- 너무 기술적인 설명
- 도구 기능만 나열하는 설명
- “완전 자동화”, “100% 대체” 같은 과장 표현
- 대표의 현재 업무 방식을 무조건 비효율적이라고 단정하는 표현

## 필요한 근거 자료

준비할 자료:

- 대표가 직접 처리하는 반복 업무 목록
- 주간 보고서, 월간 보고서 샘플
- 고객 문의 유형과 응대 시간
- 제안서 또는 견적서 작성 과정
- 현재 사용하는 도구 목록
- 자동화하면 위험한 업무와 자동화해도 되는 업무 구분

자료 보관 위치:

## 아직 확인할 질문

- 고객사는 어떤 업종인가?
- 현재 직원 수는 몇 명인가?
- 대표가 가장 많이 시간을 쓰는 반복 업무는 무엇인가?
- 고객 문의는 어디로 들어오는가? 예: 이메일, 카카오톡, 전화, 홈페이지
- 보고서는 어떤 주기로 작성하는가?
- 현재 사용하는 도구는 무엇인가? 예: 엑셀, 구글 시트, 노션, 슬랙, 카카오워크
- 4주 컨설팅 후 가장 먼저 자동화되길 원하는 업무는 무엇인가?
- 자동화 결과를 누가 관리할 예정인가?
