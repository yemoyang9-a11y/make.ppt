# 디자인 가이드: 프리미엄 그린 카페 무드

## 문서 목적

이 문서는 한글 제안서용 PPT를 만들기 전에 디자인 방향을 정리한 가이드입니다.  
특정 브랜드의 이름, 로고, 제품, 매장, 멤버십 예시는 사용하지 않고, 따뜻한 카페 느낌과 신뢰감 있는 초록색 분위기만 참고합니다.

## 디자인 핵심 방향

전체 분위기는 **따뜻하고 깔끔한 프리미엄 카페 무드**입니다.  
차가운 흰색 화면보다는 부드러운 크림색 배경을 사용하고, 깊은 초록색으로 신뢰감과 안정감을 줍니다.

핵심 느낌:

- 따뜻함
- 신뢰감
- 차분함
- 고급스러움
- 읽기 쉬움

피해야 할 느낌:

- 특정 브랜드를 떠올리게 하는 로고나 문구
- 커피 브랜드의 실제 메뉴, 매장, 앱 화면 예시
- 너무 강한 광고 느낌
- 색이 많고 복잡한 화면
- 글자가 빽빽한 보고서 느낌

## 색상 가이드

### 기본 색상

| 역할 | 색상 | 사용 위치 |
|---|---:|---|
| 딥 그린 | `#1E3932` | 표지, 핵심 메시지, 마지막 요청 슬라이드, 진한 배경 |
| 메인 그린 | `#006241` | 제목, 강조 문구, 핵심 숫자 |
| 액션 그린 | `#00754A` | 버튼, 진행 표시, 긍정 메시지 |
| 민트 그린 | `#D4E9E2` | 연한 강조 배경, 보조 박스 |
| 웜 크림 | `#F2F0EB` | 전체 배경, 구분 영역 |
| 세라믹 베이지 | `#EDEBE9` | 보조 배경, 표 영역 |
| 화이트 | `#FFFFFF` | 카드, 표, 본문 영역 |
| 소프트 블랙 | `rgba(0,0,0,0.87)` | 제목과 본문 |
| 보조 회색 | `rgba(0,0,0,0.58)` | 설명, 출처, 주석 |
| 프리미엄 골드 | `#CBA258` | 중요한 성과, 등급, 특별 강조 |

### 색상 사용 규칙

- 한 슬라이드에서 주된 색은 **초록 1개 + 배경색 1개**를 기본으로 합니다.
- 골드는 자주 쓰지 않고, 중요한 성과나 특별한 포인트에만 사용합니다.
- 빨간색은 문제, 위험, 감소, 경고를 보여줄 때만 사용합니다.
- 배경은 순백색만 쓰기보다 크림색을 섞어 부드럽게 만듭니다.
- 진한 초록 배경 위에는 흰색 글자를 사용합니다.

## 글꼴 가이드

### 추천 글꼴

한글 제안서에서는 누구나 열어도 깨지기 쉬운 전용 글꼴보다 기본 글꼴을 우선합니다.

- 제목: `Pretendard`, `Noto Sans KR`, `맑은 고딕`
- 본문: `Pretendard`, `Noto Sans KR`, `맑은 고딕`
- 숫자: `Pretendard`, `Arial`, `맑은 고딕`

### 글자 크기 기준

| 역할 | 권장 크기 | 굵기 |
|---|---:|---:|
| 표지 제목 | 36~44pt | 굵게 |
| 슬라이드 제목 | 26~32pt | 굵게 |
| 핵심 문장 | 22~28pt | 굵게 또는 보통 |
| 본문 | 16~21pt | 보통 |
| 표 안 글자 | 12~16pt | 보통 |
| 출처/주석 | 10~12pt | 보통 |

### 글쓰기 규칙

- 제목은 슬라이드의 결론처럼 씁니다.
- 한 문장은 짧게 씁니다.
- 한 슬라이드에 본문 문장은 3~5줄 정도로 제한합니다.
- 어려운 단어는 쉬운 말로 바꿉니다.
- 영어 약어를 쓸 때는 처음 한 번은 뜻을 함께 적습니다.

예시:

- 나쁜 예: `Customer Retention Improvement Strategy`
- 좋은 예: `고객이 다시 찾아오게 만드는 전략`

## 레이아웃 가이드

### 기본 원칙

- 한 슬라이드에는 한 가지 핵심 메시지만 담습니다.
- 제목은 위쪽에 두고, 핵심 내용은 가운데에 배치합니다.
- 여백을 넉넉하게 둡니다.
- 박스와 선을 너무 많이 쓰지 않습니다.
- 표나 그래프는 결론이 먼저 보이게 만듭니다.

### 추천 화면 구성

1. **크림 배경 + 흰색 카드**
   - 부드럽고 안정적인 제안서 느낌을 줍니다.
   - 문제, 해결책, 기대 효과를 카드 3개로 보여줄 때 좋습니다.

2. **딥 그린 배경 + 흰색 글자**
   - 표지, 핵심 메시지, 마무리 요청에 적합합니다.
   - 중요한 슬라이드라는 느낌을 줍니다.

3. **왼쪽 메시지 + 오른쪽 이미지**
   - 제안의 분위기나 사용 장면을 보여줄 때 좋습니다.
   - 이미지는 발표 주제와 직접 관련 있는 것으로 사용합니다.

4. **상단 결론 + 하단 그래프**
   - 숫자 근거를 설명할 때 좋습니다.
   - 그래프 제목에는 단순한 이름보다 결론을 적습니다.

## 구성 요소 스타일

### 카드

사용 위치:

- 문제 3가지
- 해결 방안 3가지
- 기대 효과 3가지
- 실행 단계

스타일:

- 배경: `#FFFFFF`
- 모서리: 10~12px 둥글게
- 그림자: 아주 약하게
- 안쪽 여백: 20~28px
- 카드 사이 간격: 16~24px

규칙:

- 카드 안에는 제목 1개, 설명 1~2줄, 필요하면 숫자 1개만 넣습니다.
- 카드가 많아질수록 글자는 줄입니다.

### 버튼 또는 요청 박스

제안서에서는 실제 버튼이 아니더라도, 마지막 요청 사항을 버튼처럼 보여주면 행동이 분명해집니다.

스타일:

- 배경: `#00754A`
- 글자: 흰색
- 모서리: 50px 둥근 알약 모양
- 문구: 짧고 직접적으로 작성

예시:

- `예산 승인 요청`
- `파일럿 진행 승인`
- `다음 미팅 일정 확정`
- `담당 부서 지정`

### 강조 라벨

사용 위치:

- `핵심 문제`
- `기대 효과`
- `확인 필요`
- `추천안`

스타일:

- 연한 민트 배경 `#D4E9E2`
- 진한 초록 글자 `#006241`
- 작은 둥근 박스
- 짧은 단어 중심

### 구분 밴드

중요한 전환이 필요한 슬라이드에는 가로로 넓은 색상 영역을 사용합니다.

사용 예:

- 문제에서 해결책으로 넘어갈 때
- 핵심 메시지를 다시 강조할 때
- 마지막 결론을 말할 때

스타일:

- 배경: `#1E3932`
- 글자: 흰색
- 보조 설명: 흰색 70% 정도의 밝기

## 이미지 가이드

### 사용할 이미지

- 제안 주제와 직접 관련된 업무 장면
- 제품, 서비스, 고객 경험을 보여주는 이미지
- 밝고 자연스러운 분위기의 사진
- 손, 노트북, 회의, 매장, 서비스 화면처럼 맥락을 보여주는 이미지

### 피해야 할 이미지

- 특정 커피 브랜드 로고가 보이는 사진
- 특정 브랜드 컵, 매장, 메뉴판, 앱 화면
- 발표 내용과 관련 없는 감성 사진
- 너무 어둡거나 흐린 사진
- 외부 브랜드의 실제 광고 이미지

### 이미지 사용 규칙

- 이미지는 장식이 아니라 내용을 설명하는 용도로 씁니다.
- 이미지 위에 글자를 올릴 때는 진한 반투명 배경을 깔아 읽기 쉽게 만듭니다.
- 한 슬라이드에 큰 이미지는 1개만 사용하는 것이 좋습니다.

## 표와 그래프 가이드

### 표

- 열과 행을 최소화합니다.
- 중요한 값은 굵게 표시합니다.
- 비교할 값만 남기고 설명 문장은 줄입니다.
- 출처는 작게 아래에 적습니다.

### 그래프

- 비교: 막대그래프
- 시간 흐름: 선그래프
- 구성 비율: 도넛그래프 또는 100% 막대그래프

그래프 제목 예시:

- 나쁜 예: `월별 매출`
- 좋은 예: `3월 이후 매출이 꾸준히 증가했습니다`

색상 규칙:

- 기본 값은 회색 또는 연한 초록으로 표시합니다.
- 가장 중요한 값만 메인 그린으로 강조합니다.
- 부정적인 값은 빨간색을 쓰되 최소한으로 사용합니다.

## 슬라이드별 디자인 제안

### 1. 표지

- 배경: 딥 그린 `#1E3932`
- 제목: 흰색, 크게
- 부제: 크림색 또는 흰색 70%
- 장식: 얇은 선, 작은 점, 부드러운 곡선 정도만 사용
- 로고: 발표 주체의 로고만 사용

### 2. 배경 설명

- 배경: 웜 크림 `#F2F0EB`
- 구성: 왼쪽 텍스트, 오른쪽 관련 이미지
- 핵심: 왜 지금 이 제안이 필요한지 보여줍니다.

### 3. 문제 정의

- 배경: 크림 또는 흰색
- 구성: 문제 카드 3개
- 강조: 문제로 인한 손해를 숫자로 보여줍니다.

### 4. 해결 방안

- 배경: 흰색
- 구성: 해결 단계 3개 또는 흐름도
- 강조: 복잡한 설명보다 순서를 쉽게 보여줍니다.

### 5. 기대 효과

- 배경: 웜 크림
- 구성: 큰 숫자 2~3개
- 강조: 메인 그린과 골드로 핵심 성과만 표시합니다.

### 6. 실행 계획

- 배경: 흰색
- 구성: 3단계 일정표
- 강조: 언제, 누가, 무엇을 하는지 쉽게 보이게 합니다.

### 7. 요청 사항

- 배경: 딥 그린
- 구성: 요청 박스 1~3개
- 강조: 발표 후 결정해야 할 내용을 분명하게 보여줍니다.

## 프롬프트 예시

아래 문장은 나중에 PPT 제작을 요청할 때 사용할 수 있는 예시입니다.  
특정 브랜드명은 넣지 않고, 분위기만 설명합니다.

1. `따뜻한 크림색 배경과 딥 그린 포인트를 사용한 한글 제안서 표지를 만들어줘. 제목은 크게, 부제는 작고 차분하게 배치해줘.`

2. `흰색 카드 3개를 사용해서 핵심 문제를 정리해줘. 배경은 웜 크림, 카드 모서리는 둥글게, 그림자는 아주 약하게 넣어줘.`

3. `딥 그린 배경 위에 흰색 핵심 문장을 크게 보여주는 전환 슬라이드를 만들어줘. 장식은 최소화하고 여백을 넉넉하게 둬.`

4. `막대그래프에서 가장 중요한 값만 메인 그린으로 강조하고, 나머지는 연한 회색으로 처리해줘. 제목은 그래프의 결론처럼 작성해줘.`

5. `마지막 슬라이드에 둥근 요청 박스 3개를 배치해줘. 문구는 예산 승인, 파일럿 진행, 다음 미팅 확정처럼 짧게 써줘.`

## 해야 할 것

- 크림색 배경과 초록색 포인트를 일관되게 사용합니다.
- 여백을 넉넉하게 둡니다.
- 둥근 카드와 둥근 요청 박스를 사용합니다.
- 제목을 결론형 문장으로 씁니다.
- 숫자와 근거는 크게, 설명은 짧게 보여줍니다.
- 발표 주체의 로고와 자료만 사용합니다.

## 하지 말아야 할 것

- 특정 외부 브랜드명, 로고, 제품명, 매장명, 멤버십명을 넣지 않습니다.
- 특정 브랜드의 실제 화면이나 광고 이미지를 따라 그리지 않습니다.
- 초록색을 너무 많이 써서 답답하게 만들지 않습니다.
- 골드를 모든 강조에 사용하지 않습니다.
- 그림자를 강하게 넣지 않습니다.
- 슬라이드마다 전혀 다른 색과 스타일을 쓰지 않습니다.

- [ ] 제목만 봐도 결론이 보이는가?
